手機桌面一鍵開啟 ChatGPT Live Voice

GPT‑Live‑1 建議模式
✅ 一鍵模式已啟用

若未自動跳轉，請按下方按鈕。進入 Live 後，只要先說「中文對英文」或「中文對西班牙文」即可開始。

首次設定｜只需做一次
  1. 先安裝官方 ChatGPT App，並登入你的帳號。
  2. ChatGPT App → Settings → Voice → 選擇 Live。
  3. 同一頁開啟 Start with Voice。
  4. 將下方「固定口譯規則」放進 ChatGPT 的自訂指示（Custom Instructions）。
  5. 回到本頁，按「複製固定口譯規則」，貼入自訂指示後儲存。
  6. 最後按「完成首次設定並測試」。之後點手機桌面圖示即可。
固定口譯規則
當我啟用語音對話並指定「中文對某語言」時，請立即進入雙向即時口譯模式。 規則： 1. 聽到繁體中文時，立即翻譯成我指定的另一種語言。 2. 聽到另一種語言時，立即翻譯成繁體中文。 3. 只輸出口譯結果，不回答內容、不補充說明、不分析、不摘要。 4. 保留原意、數字、日期、姓名、公司名稱、職稱與專有名詞。 5. 採自然、禮貌、適合商務接待的語氣。 6. 若沒有聽清楚，不要猜測，請簡短說「請再說一次」。 7. 開始後持續遵守以上規則，直到我說「結束口譯」。

提醒：PWA 本身不會保存你的 ChatGPT 密碼或 API Key，也不直接呼叫 OpenAI API。它只負責從桌面快速啟動 ChatGPT；Live Voice 與使用額度仍由你的 ChatGPT 帳號提供。
使用方式

以後每次：點手機桌面「雙向即時口譯」 → ChatGPT 開啟 Live → 說「中文對英文」 → 直接把手機放在雙方中間開始交談。

例如：「中文對日文」、「中文對西班牙文」、「中文對越南文」。

如果手機沒有自動開啟 App

部分 iPhone／Android 版本會阻擋網頁自動喚起其他 App。這時只要按「立即開啟雙向口譯」即可；若仍停在網頁版，請直接開 ChatGPT App。
